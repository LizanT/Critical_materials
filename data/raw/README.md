# Raw data

Source: USGS, *Mineral Commodity Summaries 2025, Data Release* (ver. 2.0, April 2025).
DOI: [10.5066/P13XCP3R](https://doi.org/10.5066/P13XCP3R). Public domain.

Expected contents:

- `World_Data.csv`: 2024 production (estimated), capacity and reserves by country and commodity.
- `Salient_Commodity_Data_Release_Grouped_MCS_2025/`: one `mcs2025-<xxxxx>_salient.csv` per commodity (prices 2020–2024) plus its `*_meta.xml`.

Download the data release from the DOI above and place the files here.
